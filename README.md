# Norse Calendar

Расширение-инфоблок для [SillyTavern](https://docs.sillytavern.app/): календарь в скандинавском стиле, встроенный в начало последнего сообщения {{char}} — как часть самого ответа. Расширение инжектит в промпт инструкцию, модель отвечает служебным блоком `<yorni>...</yorni>` с метаданными сцены, а виджет рендерит из него эйкту, положение солнца, дату, день недели и фазу Луны в формате **YORNIE**. **Реальное время не используется** — только данные из чата.

## Как это работает

1. **Промпт** — перед генерацией расширение подмешивает в запрос инструкцию (отключается в настройках).
2. **Инфоблок** — модель в самом начале ответа выводит блок `<yorni>` с полями `eykt`, `date`, `weather`, `location`, `mood`, `user_attire`, `char_attire`, `thought`.
3. **Регексы** — при первой установке расширение регистрирует в SillyTavern два regex-скрипта: первый скрывает сырой блок из отображения чата, второй вырезает старые блоки из контекста (последний остаётся как опора для state tracking). Дальше расширение их не трогает: если отредактировать или отключить скрипт в UI Regex, изменения переживут перезагрузку. Вернуть эталонные скрипты можно кнопкой **Восстановить regex-скрипты** в настройках.
4. **Виджет** — из последнего блока `<yorni>` рендерится панель YORNIE в начале последнего сообщения персонажа.

## Формат YORNIE

Шапка виджета (видна всегда):

```
[время (на русском)] • [номер эйкты]
[положение солнца]

[Эмодзи и сезон] • [день, месяц (на русском), год]
[день недели] • [эмодзи и фаза луны, объяснение фазы]
```

Заполненный пример:

```
Хадеги • 5-я эйкта
Солнце строго на Юге

❄️ Vetr • 13 Гормануд 1015
День Солнца • 🌑 Ný время зарождения и планов
```

Справа от календаря — колонки с погодой, локацией, раскрывающимися карточками {{char}} (настроение, одежда, мысль) и {{user}} (одежда).

### Кликабельные подсказки

По клику на **отдельное слово** только оно на **5 секунд** заменяется адаптацией (и подсвечивается), затем возвращается назад. Остальной текст строки не меняется.

| Кликабельное слово | Адаптация |
|---|---|
| Эйкта (Хадеги) | `12:30` (HH:MM) |
| Сезон (Vetr) | `Зима` |
| Месяц (Гормануд) | `Ноябрь` (современный месяц) |
| День недели (День Солнца) | `Воскресенье` |
| Фаза луны (Ný) | `Новолуние` |
| Дата в Auknætr | Пояснение про особые дни перед сенокосом |

По кнопке **+/–** в шапке разворачивается сетка актуальной недели с подсветкой текущего дня.

- 📌 Виджет живёт в начале последнего сообщения персонажа и переживает свайпы/редактирования
- 💡 Кликабельные адаптации слов на 5 секунд
- 🧹 Сырой блок `<yorni>` автоматически скрывается из чата и вырезается из контекста
- 📜 Tímatal — справочник по лору в меню «волшебной палочки», с подсветкой текущей сцены

- ⌨️ Slash-команды для STscript

## Tímatal — мини-справочник

**Tímatal** (др.-исл. «счёт времени») — окно со всем лором, чтобы не лезть в заметки посреди ролевой. Открывается из меню **«волшебной палочки»** рядом с полем ввода (иконка свитка) или командой `/norse-lore`.

Пять разделов:

| Раздел | Что внутри |
|---|---|
| 🧭 **Эйкты** | Все восемь: древнескандинавское написание, транслит, русский, часы, значение и положение солнца |
| 🌿 **Месяцы** | Зима и лето по порядку лорного года (год начинается с Gormánaður), с переводом каждого названия |
| 🪓 **Дни недели** | Древнескандинавское, английское, русское написание и в честь кого назван день |
| 🌕 **Луна** | Пять фаз, дни цикла и лорное описание |
| ᚱ **Блок** | Шпаргалка по формату `<yorni>` и по тому, какие даты понимает парсер |

### Справочник настраивается под себя

Показывать всё сразу нужно редко, поэтому справочник собирается под задачу — и настройки запоминаются между открытиями.

- **Разделы сворачиваются** кликом по заголовку. По умолчанию открыты только Эйкты: с телефона не приходится листать весь справочник, нужный раздел разворачивается одним касанием.
- **Колонки выбираются облачками** над таблицей. Затемнённое облачко — колонки нет, зажжённое — есть; выбор множественный. Никаких узких обрубков в таблице: выключенная колонка исчезает целиком.
- **Постоянные колонки** не выключаются — это опора таблицы. Древнескандинавское написание есть везде, а в Эйктах к нему добавляется номер: он прижат вплотную к названию, чтобы номер и имя читались как одно целое.
- Выбор **общий для всех таблиц**: включили «Транслит» — он появился и в эйктах, и в месяцах. Настроили один раз — весь справочник стал таким, как нужно.
- При первом открытии видны `#`, «Др.-сканд.» и «Русский» — остальное добирается облачками.
- Кнопка **«Сбросить вид»** возвращает всё как было. Она появляется в шапке только тогда, когда вид отличается от исходного.

Если в чате уже есть инфоблок, сверху появляется строка **«Сейчас в сцене»**, а текущая эйкта, месяц, день недели и фаза Луны подсвечиваются прямо в таблицах — видно не только «какие бывают», но и «где мы сейчас».

Окно целиком — включая подложку, рамку и затемнение фона — красится темой расширения и **не зависит от темы интерфейса SillyTavern**: меняете тему таверны, Tímatal остаётся своим. Переопределение переживает даже пользовательские темы и User CSS, которые ставят `!important` на `.popup`.

## Slash-команды

| Команда | Возвращает |
|---|---|
| `/norse-date` | Дату из последнего блока `<yorni>`, например `13 Гормануд 1015` |
| `/norse-eykt` | Название текущей эйкты, например `Хадеги` |
| `/norse-state` | Всё состояние виджета в JSON: дата, время, погода, локация, настроение, одежда, мысль |
| `/norse-refresh` | Ничего — принудительно перечитывает чат и перерисовывает виджет |
| `/norse-lore` | Ничего — открывает справочник Tímatal (алиас `/timatal`) |

Если инфоблока в чате ещё нет, `/norse-date` и `/norse-eykt` возвращают пустую строку.

## Установка

### Через интерфейс SillyTavern (рекомендуется)

1. Открой SillyTavern → панель расширений (иконка кубиков) → **Install Extension**.
2. Вставь ссылку на репозиторий:
   ```
   https://github.com/yornn/Norse-Calendar
   ```
3. Дождись установки и перезагрузи страницу.

### Вручную

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/yornn/Norse-Calendar
```

Затем перезагрузи страницу SillyTavern. В списке расширений появится **Norse Calendar**.

### Дополнительные дни (Sumarauki / Auknætr)

По правилам этого календаря к 360 дням (12 месяцев по 30 дней) в середине лета — между месяцами Sólmánuður (июль) и Heyannir (август) — добавляется особый период из **4 дней (в високосный год — 5)**. Год получается 364 дня, в високосный 365.

> Это лорное правило, а не астрономическая коррекция: реальный исландский календарь состоял из 52 недель (364 дня) и вставной **недели** раз в 5–6 лет. Здесь Sumarauki задаёт ритм повествования, а не выравнивает календарь с солнечным годом.

**Sumarauki (Auknætr) — Summer Addition (Extra Nights) — Летнее прибавление (Дополнительные ночи)** — 4 особых дня в середине лета перед сенокосом.

В этот период строка даты показывает `🌿 Sumar • Sumarauki 2 из 4, 875`, а вместо сетки недели — заголовок «— Sumarauki · Auknætr —» и 4–5 ячеек-«ночей». Формат в блоке: `date: 2 Auknætr 875`.

## Парсинг даты из инфоблока

Поле `date` блока `<yorni>` разбирается максимально лояльно. Поддерживаемые форматы:

| Формат | Пример |
|---|---|
| День + месяц словом | `12 March 875`, `12 марта 875`, `12 Góa 875`, `3rd of May 2024` |
| Месяц словом + день | `March 12, 875`, `Góa 12, 875` |
| ISO-подобный | `875-03-12` |
| Числовой | `12.03.875`, `12/03/875`, `21/10/23` (год 20xx) |
| Составной | `14 Gormánaður - Gormanud - Гормануд — Ноябрь 875` |
| Auknætr | `2 Auknætr 875`, `2 Sumarauki 875` |

Время (поле `eykt`) понимает как точное `ЧЧ:ММ`, так и название эйкты (`Hádegi`, «вечер», «morning»…) — тогда берётся середина эйкты.

Защита от мусора: год только 3–4 цифры (либо двухзначный → 20xx), день 31 поджимается до 30, литеральные плейсхолдеры вида `<Day VikingMonth Year>` и неподставленные макросы вида `{{char}}` отбрасываются. Обычный текст со знаками `>` `<` или в фигурных скобках (`ветер > 15 м/с`, `{радость}`) плейсхолдером не считается.

**Поля разбираются независимо.** Если строку `date` распознать не удалось, погода, локация, настроение, одежда и мысль всё равно попадут в виджет — просто без календаря и сетки дней. Так же и наоборот: блок с одной датой отрисует календарь без правых колонок.

## Структура

```
Norse-Calendar/
├── manifest.json    # метаданные расширения
├── index.js         # промпт, regex-скрипты, рендер YORNIE, slash-команды, настройки
├── parser.js        # лор и парсер блока <yorni> — общий для расширения и теста
├── reference.js     # Tímatal: окно справочника из «волшебной палочки»
├── style.css        # стили виджета
├── settings.html    # панель настроек в UI SillyTavern (исходный язык — английский)
├── i18n/            # переводы панели настроек и подписей виджета
│   ├── ru-ru.json
│   └── uk-ua.json
├── fonts/           # шрифт Norse
└── test-parse.mjs   # тест парсинга и календарной математики (node test-parse.mjs)
```

`parser.js` не зависит от SillyTavern, поэтому один и тот же код разбора работает и в браузере, и в тесте — дублирования логики нет.
