# Norse Calendar

Простое расширение-виджет для [SillyTavern](https://docs.sillytavern.app/): плавающий календарь с часами в скандинавском стиле, который подхватывает дату и время из «инфоблока» в сообщениях чата. Чисто визуальное расширение — на генерацию и контекст оно не влияет.

## Возможности

- 🗓 Календарь месяца с подсветкой текущей даты из чата
- 🕰 Часы со временем из чата
- ⚔ Скандинавские названия месяцев и дней недели (Þorri, Gói, þórsdagr…) — отключается
- 🖱 Перетаскиваемый, сворачиваемый виджет (позиция сохраняется)
- 🕯 Fallback на реальные дату/время, если в чате даты нет (отключается)
- ⏳ Опционально: время чата «тикает» в реальном темпе
- 🔧 Поддержка собственного regex для инфоблока

## Установка

### Через интерфейс SillyTavern (рекомендуется)

1. Открой SillyTavern → панель расширений (иконка кубиков) → **Install Extension**.
2. Вставь ссылку на репозиторий:
   ```
   https://github.com/yornn/Norse-Calendar
   ```
3. Дождись установки и перезагрузи страницу.

### Вручную

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/yornn/Norse-Calendar
```

Затем перезагрузи страницу SillyTavern. В списке расширений появится **Norse Calendar**.

## Как расширение находит дату

Виджет сканирует последние ~25 сообщений чата (с конца) и ищет первую подходящую дату. Поддерживаемые форматы из коробки:

| Формат | Пример |
|---|---|
| День + месяц словом (en) | `12 March 875`, `March 12, 875`, `3rd of May 2024` |
| День + месяц словом (ru) | `12 марта 875`, `3 мая 2024` |
| ISO-подобный | `875-03-12` |
| Числовой | `12.03.875`, `12/03/875` |
| Скандинавские месяцы | `12 Gói 875`, `12 Þorri 875` |

Время ищется в том же сообщении как первое вхождение `ЧЧ:ММ` (например, `14:30`).

Рекомендуемый формат инфоблока в промпте/ответах модели:

```
[Date: 12 Gói 875 | Time: 14:30]
```

### Свой regex

Если твой инфоблок имеет особый формат, задай в настройках расширения свой regex с именованными группами `day`, `month`, `year`, `hour`, `minute`, например:

```
Date: (?<day>\d+) (?<month>\w+) (?<year>\d+) \| Time: (?<hour>\d+):(?<minute>\d+)
```

`month` может быть числом (1–12) или названием месяца (en/ru/norse). Если поле пустое — используются встроенные форматы.
