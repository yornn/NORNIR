# Norse Calendar

Расширение-инфоблок для [SillyTavern](https://docs.sillytavern.app/): календарь в скандинавском стиле, встроенный в начало последнего сообщения {{char}} — как часть самого ответа. Расширение инжектит в промпт инструкцию, модель отвечает служебным блоком `<yorni>...</yorni>` с метаданными сцены, а виджет рендерит из него эйкту, положение солнца, дату, день недели и фазу Луны в формате **YORNIE**. **Реальное время не используется** — только данные из чата.

## Как это работает

1. **Промпт** — перед генерацией расширение подмешивает в запрос инструкцию (отключается в настройках).
2. **Инфоблок** — модель в самом начале ответа выводит блок `<yorni>` с полями `eykt`, `date`, `weather`, `location`, `mood`, `user_attire`, `char_attire`, `thought`.
3. **Регексы** — расширение регистрирует в SillyTavern два regex-скрипта: первый скрывает сырой блок из отображения чата, второй вырезает старые блоки из контекста (последний остаётся как опора для state tracking).
4. **Виджет** — из последнего блока `<yorni>` рендерится панель YORNIE в начале последнего сообщения персонажа.

## Формат YORNIE

Шапка виджета (видна всегда):

```
[время (на русском)] • [номер эйкты]
[положение солнца]

[Эмодзи и сезон] • [день, месяц (на русском), год]
[день недели] • [эмодзи и фаза луны, объяснение фазы]
```

Заполненный пример:

```
Хадеги • 5-я эйкта
Солнце строго на Юге

❄️ Vetr • 13 Гормануд 1015
День Солнца • 🌑 Ný время зарождения и планов
```

Справа от календаря — колонки с погодой, локацией, раскрывающимися карточками {{char}} (настроение, одежда, мысль) и {{user}} (одежда).

### Кликабельные подсказки

По клику на **отдельное слово** только оно на **5 секунд** заменяется адаптацией (и подсвечивается), затем возвращается назад. Остальной текст строки не меняется.

| Кликабельное слово | Адаптация |
|---|---|
| Эйкта (Хадеги) | `12:30` (HH:MM) |
| Сезон (Vetr) | `Зима` |
| Месяц (Гормануд) | `Ноябрь` (современный месяц) |
| День недели (День Солнца) | `Воскресенье` |
| Фаза луны (Ný) | `Новолуние` |
| Дата в Auknætr | Пояснение про особые дни перед сенокосом |

По кнопке **+/–** в шапке разворачивается сетка актуальной недели с подсветкой текущего дня.

## Возможности

- 🧭 Текущая эйкта + положение солнца
- ❄🌿 Сезон (Vetr / Sumar) + дата русским викингским месяцем
- 🌕 Фаза Луны (Tungl) с лорным описанием
- 📅 Разворачиваемая сетка недели
- 🌒 Особый статус Sumarauki / Auknætr (4–5 дополнительных дней)
- 🌦️ Погода, локация, одежда и мысль персонажа из инфоблока
- 📌 Виджет живёт в начале последнего сообщения персонажа и переживает свайпы/редактирования
- 💡 Кликабельные адаптации слов на 5 секунд
- 🧹 Сырой блок `<yorni>` автоматически скрывается из чата и вырезается из контекста

## Установка

### Через интерфейс SillyTavern (рекомендуется)

1. Открой SillyTavern → панель расширений (иконка кубиков) → **Install Extension**.
2. Вставь ссылку на репозиторий:
   ```
   https://github.com/yornn/Norse-Calendar
   ```
3. Дождись установки и перезагрузи страницу.

### Вручную

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/yornn/Norse-Calendar
```

Затем перезагрузи страницу SillyTavern. В списке расширений появится **Norse Calendar**.

### Дополнительные дни (Sumarauki / Auknætr)

Чтобы выровнять 360 дней (12 месяцев по 30 дней) с солнечным годом, в середине лета между месяцами Sólmánuður (июль) и Heyannir (август) вставляется особый период из **4 дней (в високосный год — 5)**.

**Sumarauki (Auknætr) — Summer Addition (Extra Nights) — Летнее прибавление (Дополнительные ночи)** — 4 особых дня в середине лета перед сенокосом.

В этот период строка даты показывает `🌿 Sumar • Sumarauki 2 из 4, 875`, а вместо сетки недели — заголовок «— Sumarauki · Auknætr —» и 4–5 ячеек-«ночей». Формат в блоке: `date: 2 Auknætr 875`.

### Луна (Tungl)

Цикл Луны длится 29.53 дня. Точка отсчёта — 6 Mörsugur 2000, что соответствует реальному астрономическому новолунию 2000-01-06 (возраст считается по дням лорного календаря). Пять фаз:

| Old Norse | English | Русский | Дни цикла | Описание |
|---|---|---|---|---|
| Ný | New Moon | Новолуние | 0 – 1.8 | время зарождения и планов |
| Vaxandi | Waxing Moon | Растущая луна | 1.8 – 13.0 | время дел, походов и строительства |
| Fullt tungl | Full Moon | Полнолуние | 13.0 – 16.5 | пик силы, время Блотов и Тинга |
| Minnandi | Waning Moon | Убывающая луна | 16.5 – 27.7 | время завершать дела и возвращаться домой |
| Nið | Dark Moon | Безлуние | 27.7 – 29.53 | ночи волка Хати, время отдыха и осторожности |

## Парсинг даты из инфоблока

Поле `date` блока `<yorni>` разбирается максимально лояльно. Поддерживаемые форматы:

| Формат | Пример |
|---|---|
| День + месяц словом | `12 March 875`, `12 марта 875`, `12 Góa 875`, `3rd of May 2024` |
| Месяц словом + день | `March 12, 875`, `Góa 12, 875` |
| ISO-подобный | `875-03-12` |
| Числовой | `12.03.875`, `12/03/875`, `21/10/23` (год 20xx) |
| Составной | `14 Gormánaður - Gormanud - Гормануд — Ноябрь 875` |
| Auknætr | `2 Auknætr 875`, `2 Sumarauki 875` |

Время (поле `eykt`) понимает как точное `ЧЧ:ММ`, так и название эйкты (`Hádegi`, «вечер», «morning»…) — тогда берётся середина эйкты.

Защита от мусора: год только 3–4 цифры (либо двухзначный → 20xx), день 31 поджимается до 30, литеральные плейсхолдеры вида `<Day VikingMonth Year>` отбрасываются.
