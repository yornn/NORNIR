# Знаки полей

Сюда кладутся иконки инфоблока. Каждый файл — один знак, имя файла и есть его
ключ: панель просит знак по имени, CSS отдаёт файл (см. раздел `14. ICONS`
в `style.css`).

## Как рисовать

- SVG, `viewBox="0 0 24 24"`, квадрат.
- **Одноцветный силуэт.** Цвет внутри файла не важен вообще: знак подкладывается
  CSS-маской, а маска берёт только альфу. Пишите хоть `fill="#000"`.
- Никаких градиентов, `opacity`, встроенных `<style>`, растровых вставок.
- Обводки не тоньше `1.8` при 24px: знак рисуется в 13–16px.
- Поля внутри `viewBox` — около 1–2px, не больше: иначе знак усохнет рядом
  с текстом.
- Стиль единый: гравюра, линия под руны. Не глянцевые эмодзи.

## Как проверить

Положить файл в эту папку и перезагрузить расширение — больше ничего не нужно,
ни манифест, ни код не правятся.

**Файла нет — рисуется `_fallback.svg`** (ромб), и вёрстка этого не замечает.
Поэтому иконки можно доносить по одной, в любом порядке, а панель всё это время
остаётся рабочей.
